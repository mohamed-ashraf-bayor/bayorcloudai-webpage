Featured MVP: SAGASQL

Our first MVP product shows how BAYOR applies Cloud + AI architecture to a real business use case: natural-language SQL generation with schema context, sandbox validation and human review

SAGASQL

A schema-driven AI workflow that turns business questions into database-specific SQL, validates the result in a cloud sandbox and returns evidence for human review

Schema-Driven Agentic SQL Generation
1

Ask

Plain-language question in supported languages

2

Schema

DDL schema plus optional client test data

3

Generate

Single-model mode for speed or two-model mode for confidence

4

Validate

Sandbox test, guardrails and SQL regeneration if needed

5

Return

SQL, explanation, test evidence and human review signal

SQL

Initial database support

PostgreSQL, MySQL and SQL Server first. More SQL dialects can be added over time.

🧪

Test data options

Generate 10, 100, 1000+ rows per table or allow clients to upload their own test data per table

Future reporting UI

Saved requests, workflow history, IDE plugin integration, charts, tables, exports and dashboards
